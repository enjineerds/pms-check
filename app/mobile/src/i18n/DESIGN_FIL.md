# Filipino copy from the design

Source: Doop canvas "PMS Check", page "Version 3 · Glossy white", the 20 `(Tagalog)` frames. Each pair is English → Filipino as drawn. `fil.ts` follows this; where a string has no frame, `fil.ts` uses the same register and words.

Verdict words: Say yes → **Oo**, Ask first → **Itanong**, Say no → **Hindi**.
